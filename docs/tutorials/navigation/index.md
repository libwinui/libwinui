# Navigation

An app frame, and the popups that float above it.

The Basics course builds one window with one form in it. A real application has more than one page, a way to move between them, and things that float above the page for a moment: a confirmation dialog, a menu, a tooltip. This track covers both halves.

Read [Events and Commands](../basics/04-events-and-commands.md) first. Both pages lean on handlers and on `.control` observers.

## The Track

| Page | What you build | Project |
| --- | --- | --- |
| [01 - An App Skeleton](01-app-skeleton.md) | A window whose content extends into the title bar, a `TitleBar` with a search box, a `NavigationShell` with three pages and Settings, and a `Tabs` of documents | `examples/tutorials/09_app_skeleton/` |
| [02 - Dialogs, Flyouts and Menus](02-dialogs-flyouts-menus.md) | A file list with a menu bar, a confirmation dialog, a flyout form, a tooltip, a drop-down menu and a context menu | `examples/tutorials/10_dialogs_flyouts_menus/` |

Run them as `tutorial_09_app_skeleton.exe` and `tutorial_10_dialogs_flyouts_menus.exe` from `build/bin/Debug/`.
